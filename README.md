# Simple translator from Eng to Rus
To start you need download project
```git
git clone https://github.com/LiKoloz/SimpleTranslatorFromEngToRus
```
Then go to the _working directory_
```
cd SimpleTranslatorFromEngToRus
```
And _start_ project
```
go run . -vendor
```

### Database

The database is implemented as a cache (map).
